# House Price Prediction with Machine Learning

Predict house prices using machine learning based on property attributes such as quality, living space, and amenities.

---

## Overview
This project builds a predictive model to estimate house prices and identify key factors affecting property values. The model is deployed as an interactive web app using Streamlit.

**Objectives:**
- Predict house prices from property features  
- Identify most influential features  
- Deploy model for user interaction

---

## Dataset
- Sourced from [Kaggle House Prices Dataset](https://www.kaggle.com/c/house-prices-advanced-regression-techniques)  
- Key features: `OverallQual`, `GrLivArea`, `TotalArea`, `GarageCars`, `YearBuilt`  

---

## Data Preparation
- Handle missing values  
- Correct data types  
- Feature engineering

---

## Model

-Linear Regression
-Decision Tree Regressor
-Random Forest Regressor

---

## Feature Importance

Top predictors:
-OverallQual (house quality)
-TotalArea (total usable space)
-GarageCars
-GrLivArea
